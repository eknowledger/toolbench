### New (6)

- **Graphs**: return nodes and edges, and the runtime lays them out and draws them.
- **Copy buttons**: copy a code result exactly, or a table straight into a spreadsheet.
- **Byte ranges in colour**: each highlighted range in a hex dump gets its own colour.
- **Textarea grammar**: a tool can highlight its own notation, with no highlighter on the page.
- **Every kind of graph**: trees, mind maps, networks, ER diagrams, swimlanes and nested groups.
- **Large graphs**: past a hundred nodes, a graph is laid out off the main thread, so the page never stalls.

### Fixed (2)

- **Version check**: a tool using a feature newer than its declared `sdk` is refused, with a message saying why. _May refuse a tool_
- **Plain wording**: status lines and messages no longer use em dashes. _Wording changed_
