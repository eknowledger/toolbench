This page is not a display mode. It is a bench fixture that times out and crashes on purpose, kept off the front page so a first visit is not a deliberate error a visitor cannot interpret.

What failure looks like

Intentional: every option below except "Work normally" is a failure path the runtime has to render. Spin forever ignores its abort signal, so only the worker timeout can stop it (about 1.5 seconds), and the page stays responsive. That is what worker mode buys. Throw is a bug in the tool, which reads differently from reject the input, which is the tool working correctly.

A card that has not drawn a chart yet

This tool returns a chart, but a closed card with no seed has nothing to draw, so the chart renderer is not fetched until the card is opened. If that fetch fails, the card still opens and says the chart could not be loaded, instead of turning into an error box.
