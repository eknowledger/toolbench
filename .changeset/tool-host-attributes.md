**New: `ToolHostAttributes`**, a type for the attributes `<tool-host>` reads (`tool`, `mode`, `parts`, `more`, `layout`, `controls`, `wide`, `wide-toggle`), each with its default and meaning, for a host typing its own markup. Types only: nothing is added to the bundle. `RegistryEntry`'s two members are described too.
