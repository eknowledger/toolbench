**New: long help behind a "More".** `details` on an input puts the rest of its help in a native disclosure under the one-line `description`, closed until the reader opens it. It takes the same markup as a description. ([#215](https://github.com/eknowledger/toolbench/issues/215))

- A screen reader on the control still hears only the description.
- Contract version 8.
