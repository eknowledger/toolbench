**New: box plots.** ([#122](https://github.com/eknowledger/toolbench/issues/122)) `shape: "box"` with a `boxes` summary per x draws whiskers, the quartile box, the median and outliers, grouped like bars. The tool computes the summary, so the whiskers mean what the tool says; the readout and the data table list all five numbers.
